Términos en lenguaje claro para usar Korean School. Al usar este sitio, aceptas estos términos.

🆓 Uso personal y educativo gratuito

Puedes usar Korean School para estudio personal y fines educativos de forma gratuita. No puedes reproducir, revender ni redistribuir el contenido del sitio como tu propio producto o servicio sin permiso.

📢 Nivel gratuito con publicidad

La mayoría de las funciones son gratuitas y se financian con publicidad. Al usar este sitio, aceptas que se pueden mostrar anuncios. Se permite el software bloqueador de anuncios, pero si muchos usuarios bloquean los anuncios, la capacidad del sitio para mantenerse gratuito puede verse afectada. Agradecemos tu apoyo.

🔮 Funciones premium próximas

Planeamos introducir texto a voz con IA (TTS) — síntesis de voz coreana de alta calidad — como función premium de pago. Los usuarios gratuitos continuarán teniendo acceso al TTS básico a través de la API Web Speech del navegador. Los detalles sobre precios y cómo suscribirse se anunciarán por separado cuando la función se lance.

⚖️ Sin garantía

Korean School se proporciona "tal cual" con fines educativos. Si bien apuntamos a la precisión, no garantizamos la integridad o corrección de ningún contenido del idioma coreano, traducción o información cultural. Usa tu mejor criterio y consulta recursos adicionales cuando sea necesario.

💾 Sin cuenta — solo progreso local

No se requiere cuenta para usar este sitio. Tu progreso se guarda solo en el almacenamiento local de tu navegador. No somos responsables de ninguna pérdida de progreso que ocurra cuando se borra el almacenamiento local, cuando cambias de navegador o cuando usas un dispositivo diferente.

Las referencias a artistas de K-pop, títulos de K-drama, marcas y otras obras culturales se utilizan para comentario educativo y pertenecen a sus respectivos titulares de derechos.
