# Korean School: Google publisher self-audit

Prepared 2 October 2026 for `freekoreanschool.com`. This is a working checklist, not Google's approval decision or a legal certification. Local source, public production, and account configuration are separate evidence sets.

Google does not supply a universal minimum word count, page count, traffic target, E-E-A-T score, or guaranteed approval probability in these documents. More pages and longer paragraphs are not substitutes for useful content. AI assistance is not an automatic ban; its purpose, accuracy, added value, and truthful presentation matter. A disclaimer does not cure an incorrect claim or copyright problem.

## Implemented content and code

- `guides/restaurant-confidence.html`: observation, table vocabulary, request/location contrast, original dialogue, recovery phrases, four explained questions, adaptation exercise, and reference scope.
- `guides/subway-first-journey.html`: route-note routine, direction/transfer/exit distinction, card-tapping reference, destination/location grammar, recovery routine, four explained questions, and operational freshness limits.
- `scripts/_quiz-explanations.cjs`: 200 explanations. Nuance includes informal politeness, omitted Korean subjects, phonetic limits of romanization, possessive 의, kinship glosses, and literal versus idiomatic meaning. Selected checks use NIKL's [romanization reference](https://www.korean.go.kr/front_eng/roman/roman_01.do) and [삼촌 entry](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=61142&nation=eng). Question/answer signatures prevent silently applying explanations to changed prompts.
- `scripts/build-publisher-readiness.cjs`: localized editorial notes, truthful About blocks, structured-data publisher identity, privacy revisions, accurate flashcard description, release marker, and verification-only script removal. This builder runs after the experience builder so routine regeneration does not undo it.
- `scripts/publisher-release.json`: records that ads and Analytics are paused. Setting a boolean is deliberately insufficient to activate them; activation needs an implemented and tested consent-aware loader and approved inventory.
- `docs/editorial-source-register.json`: claim-level source scope for selected companions. Not a substitute for the remaining legacy source review.
- `vercel.json`, `.vercelignore`, `404.html`: locale route repair, private-file exclusions, and a recovery page.

## Reproduce evidence

```powershell
node scripts/build-study-guides.cjs
node scripts/build-experience.cjs
node scripts/gen-sitemap.cjs
node scripts/audit-publisher-readiness.cjs
node scripts/audit-publisher-readiness.cjs --live

# Temporary QA dependency installed outside the site:
$env:KS_QA_MODULE_PATH = "$env:TEMP/ks-experience-qa/node_modules/playwright"
node scripts/check-publisher-readiness.cjs
node scripts/check-experience.cjs
node scripts/check-renovation.cjs
node scripts/audit-i18n.cjs --check
```

`audit-publisher-readiness.cjs --live` intentionally exits with a failure when production is stale. Its failure must not be renamed a pass or hidden by local QA. It records HTTP evidence, not a crawler/account verdict. Avoid running its private-path probes against the unrestricted development server and interpreting that as production access control.

Evidence files: `publisher-audit/static.json`, `publisher-audit/live.json`, `publisher-audit/media-inventory.json`, `publisher-audit/browser.json`; existing `experience-qa/`, `renovation-qa/`, and locale audit outputs. Browser checks block optional external providers and therefore do not establish real speech playback, external image rights, production ads, or field performance.

Verified local evidence: 471 public HTML pages have the release marker and matching AdSense verification tag; all 400 course/library/quiz pages have editorial notes; zero ad or Analytics loaders remain. The new guides have eight explained questions. The English quiz has 200 authored explanations and nine translated quizzes provide 1,800 corresponding English links. The locale audit passes 16/16 structural invariants and resolves 1,190 search destinations, while still reporting 7,217 residual English characters in 180 localized culture/travel pages. These results do not certify native fluency, copyright ownership, or account readiness. All 177 static img sources match existing generation records; the inventory expressly excludes CSS backgrounds, srcset alternatives, and runtime-loaded images. Regeneration preserved the hashes of all 471 public HTML files in the recorded check. The final disclosure-only paragraph addition uses the same publisher builder.

## Before ad activation or requesting a new review

- [ ] Deploy the actual reviewed release to the existing production project; rerun the live audit and production browser checks. Do not apply to an older release while assessing new local content.
- [ ] Resolve image ownership/licence records and verify consequential factual claims in legacy culture/travel articles. No guessed “fair use” status.
- [ ] Review Korean examples and key translations, fixing mistakes in both source and affected locales. Keep review claims tied to work actually done.
- [ ] In AdSense, verify the site/publisher, actual approval status, ads.txt authorization, and any account issues. These are unavailable from public HTML.
- [ ] Before personalized European-region ads, publish and test the applicable certified CMP setup. Check withdrawal and non-consenting behavior, as well as consenting behavior.
- [ ] Implement consent-aware script loading, maintain the ad-free screen exclusions, and inspect actual Auto Ads placements around practice controls at mobile and desktop widths.
- [ ] Inspect crawler/account reports and real-user performance. Record what was observed, not an assumed approval score.
