How to use:  1. Enter your service role key and click Save to browser.  2. Click Load Articles to fetch all articles from Supabase.  3. For each row, click Choose File and pick a WebP image (any format accepted — resized & converted automatically to 640 × 360 px WebP).  4. Click Upload All — each image is uploaded to site-images/article-thumb/{slug}.webp and the article's thumbnail_url is updated in the database.  5. Green rows = done. Red rows = check console for the error.

Tip: Rows with a current thumbnail shown in the Current column already have one. Use the Re-upload already uploaded checkbox only if you want to overwrite them.
