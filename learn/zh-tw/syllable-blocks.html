韓語音節積木: 음절 구조

閱讀解說和例句，再依自己的步調練習。完整教材都在這一頁。

積木基礎 블록 기초

什麼是音節方塊？ 음절이란?

每個韓語音節都寫在一個隱形的方形區塊內。不像英文字母從左到右一字排開，韓語將子音和母音堆疊在一個緊湊、視覺上均衡的方塊中。每個方塊恰好代表一個音節——一個發音單位。

你知道嗎？

每個音節方塊一定只有一個母音。它可以有0個、1個或2個子音——但絕對不超過一個母音。

三個位置 세 가지 자리

每個韓語音節方塊有三個命名位置。兩個是必要的（초성：第一個子音；중성：母音），一個是可選的（받침：最後的子音）。熟記這些位置名稱非常重要——韓語文法中會頻繁提到它們。

提示

對於直立型母音（ㅏ、ㅓ、ㅣ）：초성在左側，母音在右側。對於水平型母音（ㅗ、ㅜ、ㅡ）：초성在上方，母音在下方。

四種音節方塊結構 네 가지 음절 패턴

韓語音節根據是否有終聲（받침）以及音節以母音或子音開頭，遵循四種基本結構模式。

結構音節組件說明
CV가ㄱ + ㅏ初聲 + 母音
V아ㅇ + ㅏ無聲ㅇ + 母音
CVC간ㄱ + ㅏ + ㄴ初聲 + 母音 + 받침（收音）
VC안ㅇ + ㅏ + ㄴ無聲ㅇ + 母音 + 받침（收音）

ㅇ 佔位符規則

當音節以母音開頭時，必須在初聲位置寫上ㅇ作為佔位符。ㅇ在音節開頭完全無聲——它只是表示該方塊以母音開頭。例如：아 = ㅇ+ㅏ　이 = ㅇ+ㅣ　우 = ㅇ+ㅜ

字母發音例字意思說明
한 ㅎ + ㅏ + ㄴhan ㄏㄢ한국韓國每個音節都是方形方塊——初聲、母音和可選的終聲。
국 ㄱ + ㅜ + ㄱguk ㄍㄨㄎ한국韓國這個方塊具有所有三個位置：초성（ㄱ）＋중성（ㅜ）＋받침（ㄱ）。
어 ㅇ + ㅓeo ㄛ한국어韓語以母音開頭的音節使用無聲的ㅇ作為佔位符。這裡的ㅇ不發音。

理解測驗

안（裡面／不）——這是什麼結構模式？

答案

母音方向 모음 방향

直立型母音與水平型母音 세로 vs 가로 모음

母音的形狀決定了初聲在方塊內的位置。高挑的直立型母音把子音推到左側；寬扁的水平型母音把子音推到上方。這就是韓語外觀呈現獨特方形的原因。

快速視覺技巧

看到高挑母音（ㅏ、ㅓ、ㅣ及其變體）時，初聲在其左側。看到寬扁母音（ㅗ、ㅜ、ㅡ及其變體）時，初聲在其上方。像ㅘ、ㅝ、ㅚ這樣的複合母音表現像直立母音——子音在左側。

너 ㄴ ← ㅓneo ㄋㄛ너你（非正式）ㅓ也是直立型母音——子音在左，母音在右。
시 ㅅ ← ㅣsi ㄙㄧ시간時間ㅣ是最高挑的母音。子音始終在其左側。
고 ㄱ ↑ ㅗgo ㄍㄛ고마워謝謝ㅗ是寬扁的水平型母音。初聲在母音的上方。
누 ㄴ ↑ ㅜnu ㄋㄨ누구誰ㅜ是寬扁的水平型母音——子音在上，母音在下。橫線朝下。
그 ㄱ ↑ ㅡgeu ㄍㄜ그리고而且，接著ㅡ是平坦的水平型母音——子音在其上方。

收音 받침

加入收音——終聲子音 받침 추가

當你在方塊底部加入子音時，該子音就成為받침（收音）——終聲子音。收音賦予許多韓語單詞豐富、共鳴的尾音。看看加入收音如何把簡單的音節轉變成真實的單詞。

提示

有收音的音節方塊在垂直方向上稍微被壓縮，以在底部騰出空間。收音子音位於初聲和母音的下方，完成方塊的方形外觀。

산 ㅅ + ㅏ + ㄴsan ㄙㄢ산山ㄴ是這裡的收音——它位於方塊底部，在ㅅ和ㅏ的下方。
달 ㄷ + ㅏ + ㄹdal ㄉㄚㄌ달月亮／月份ㄹ收音——舌頭輕輕點擊上顎。
밥 ㅂ + ㅏ + ㅂbap ㄅㄚㄅ밥米飯／餐食ㅂ收音——語末嘴唇閉合不放開。「p」音不送氣。
봄 ㅂ + ㅗ + ㅁbom ㄅㄛㄇ봄春天（季節）ㅁ收音——語末嘴唇輕柔閉合。鼻腔共鳴的尾音。
길 ㄱ + ㅣ + ㄹgil ㄍㄧㄌ길道路／方向再次出現ㄹ收音——舌頭停留在上顎。像輕柔的「l」音。

練習與總結 연습

恭喜——你已學會韓語音節方塊的核心結構！以下是管理韓語書寫系統中每個音節的五條規則的簡要總結。

  • 每個方塊恰好只有一個母音（중성／中聲）
  • 以母音開頭的音節使用無聲的ㅇ作為初聲佔位符
  • 直立型母音（ㅏ、ㅓ、ㅣ）——初聲在左側，母音在右側
  • 水平型母音（ㅗ、ㅜ、ㅡ）——初聲在上方，母音在下方
  • 可選的받침（收音）位於方塊底部，在所有元素的下方

即將進行自測！
