Expressing 感情 — 감정 표현

解説と例文を読み、自分のペースで練習しましょう。教材はすべてこのページにあります。

基本感情 기본 감정

韓国語の感情（감정）

韓国語の感情語は、基本形がほとんど形容詞です。英語では「I am happy」と言いますが、韓国語の形容詞は動詞のように直接活用します：행복해요（幸せです）のように、別の「am/is/are」に相当する語は不要です。辞書形は-다で終わります：행복하다、슬프다、무섭다。-다を取って-아요/-어요を付ければ丁寧な現在形になります。感情語彙は、Kドラマ・日常生活・気持ちの表現に特に役立ちます。

形容詞が動詞のように活用する

행복하다 → 행복해요（幸せです）。슬프다 → 슬퍼요（悲しいです）。피곤하다 → 피곤해요（疲れています）。-아요/-어요語尾が形容詞を丁寧な現在形にします。

理解度チェック

「幸せだ」を意味する語はどれでしょう。

解答

행복하다

感情形容詞の活用 감정 형용사 활용

感情形容詞を丁寧な会話で使うには、辞書形から-다を取り除き、丁寧な現在形語尾を付けます。語幹が하で終わる場合：하다 → 해요（행복하다 → 행복해요）。語幹の最後の母音が明るい母音（ㅏ・ㅗ）の場合：-아요を付けます。その他の場合：-어요を付けますが、多くは母音が変化します——슬프다は語幹のㅡが脱落し、슬프 + 어요 → 슬퍼요。語幹がㅂで終わる語はㅂ不規則で、ㅂが우に変わります。したがって무섭다 → 무서우 + 어요 → 무서워요（同様に외롭다 → 외로워요、부끄럽다 → 부끄러워요）。同じパターンがほとんどの韓国語の記述動詞（形容詞）に適用されます。

活用早見表

행복하다 → 행복해요。슬프다 → 슬퍼요。화나다 → 화나요。무섭다 → 무서워요。피곤하다 → 피곤해요。기쁘다 → 기뻐요。슬프다は-어요の前に으が脱落することに注意。

感情表現 감정 표현

もっと感情の言葉（감정 어휘）

韓国語には、基本的な感情語を超えた豊かな語彙があります。기쁘다（嬉しい・喜んでいる）は행복하다よりもやや強い・特定の喜びを表します。걱정되다（心配だ）は文字通り「心配が起こる/なる」を意味します。신나다（興奮する・テンションが上がる）はコンサート・スポーツ・お祝いなどエネルギッシュな場面によく使われます。피곤하다（疲れている）は日常生活に欠かせない語で、特に何かできない理由を説明するときに重要です。

신나다はポップカルチャーで頻出

신나다と신나요は韓国のポップカルチャーのあちこちに登場します。K-popの曲では신나を盛り上がるビートや雰囲気の表現によく使います。イベントやパーティーでは 신난다! という感嘆表現もよく聞きます。

기분——気分と感情

기분（ギブン）は気分や全般的な感情状態を表す核心的な言葉です。기분이 좋다＝気分がいい。기분이 나쁘다＝気分が悪い。기분 は一つの感情語よりも広く感情のトーンを表現できます——全体的な状態を指します。日常会話で 기분이 어때요?（気分はどうですか?）をよく聞きます。

기분 vs 감정

기분 ＝ 気分・一般的な感情状態（文脈による、変化しやすい）。감정 ＝ 感情（怒り・喜び・恐怖などより具体的な気持ち）。기분이 좋아요 ＝ 今気分がいいです。감정을 표현하다 ＝ 感情を表現する。

複雑な感情 복잡한 감정

より深い感情（깊은 감정）

韓国語には、英語で一語に訳せない感情語がいくつかあります。그립다（geuripda）は、離れた人や場所への切ない恋しさ・憧れを表します。외롭다（oeropda）は孤独ですが、孤立の文化的な深みを持ちます。부끄럽다（bukkeureupda）は恥ずかしさや内気さです。뿌듯하다（ppudeuthada）は、何かを成し遂げたときや、大切な人の成功を見守ったときに感じる温かな誇りや充実感です。

한（恨）——翻訳不能な韓国の悲哀

한（ハン）は文化固有の感情：歴史的苦難に根ざしながら創造的エネルギーへと昇華される深い悲しみと粘り強さが混じり合ったもの。パンソリ（韓国の民族歌劇）に聞こえ、詩に描かれ、韓国のアイデンティティを語る文脈で言及されます。気軽に使う言葉ではありませんが、文化的理解には欠かせません。

感情フレーズ 감정 문장

感情を表すよく使う文型 감정 표현 문장

韓国語で感情を表現する際に特に役立つ文型がいくつかあります。「보고 싶어요」（会いたい・恋しい）は 보다（見る）＋ -고 싶다（したい）を使います。「감동받았어요」（感動しました）は 감동（深い感情）＋ 받다（受け取る）を使います。「괜찮아요」（大丈夫です）は最も汎用性の高いフレーズの一つで、「大丈夫」「いいよ」「問題ない」「気にしないで」のすべてに使えます。

괜찮아요 ——多用途フレーズ

괜찮아요は文字通り「大丈夫です/よいです」を意味します。転んだ後に「大丈夫」と伝えるとき、断ったオファーを受け入れるとき、「いいえ結構です」と言うとき、「それで構いません」を表すとき——すべてに使えます。トーンをマスターするのが鍵——同じ言葉でも全く違うメッセージになります。
