Korean Syllable Blocks: 음절 구조

🎯 5 Stages · 61 Steps 📊 Beginner ⏱️ ~50 min ⚡ XP + Streak system
  • Every syllable is a compact square block — not a horizontal letter string
  • Each block holds exactly 1 vowel plus up to 2 consonants
  • 4 structural patterns: CV, V, CVC, VC — all follow the same rules
  • Master the block structure and you can sound out any Korean word
