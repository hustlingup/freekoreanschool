การพิมพ์ภาษาเกาหลี ⌨️

เกาหลีพิมพ์ด้วยแป้นพิมพ์แบบดูบอลชิก (두벌식, "2 ชุด"): พยัญชนะอยู่ครึ่งซ้ายของแป้นพิมพ์ สระอยู่ทางขวา เรียนรู้ตำแหน่งของตัวอักษรแต่ละตัว แล้วฝึกจนบล็อกประกอบขึ้นเองได้

🎯 6 ระยะ · 29 ขั้นตอน 📊 ผู้เริ่มต้น ⏱️ ~38 นาที 🔥 สตรีคประจำวัน + ติดตามความคืบหน้าจริง
  • แป้นพิมพ์ 두벌식 (ดูบอลชิก, 2 ชุด) ทั้งหมด ทีละปุ่ม — พยัญชนะอยู่ด้านซ้าย สระอยู่ด้านขวา พยัญชนะเสียงหนักอยู่ที่ปุ่ม Shift
  • วิธีที่ตัวอักษรประกอบเป็นบล็อกขณะพิมพ์: ㅎ + ㅏ + ㄴ กลายเป็น 한 และพยัญชนะท้ายจะย้ายไปบล็อกถัดไปเมื่อมีสระตามมา
  • แบบฝึกสามระดับ — จาโมเดี่ยว จากนั้นพยางค์ทั้งที่มีและไม่มีพัชชิม แล้วจึงเป็นคำและวลีจริง
  • แบบฝึกทุกชุดให้คะแนนคุณเป็น 타/분 (ตัวอักษรต่อนาที) พร้อมความแม่นยำแบบเรียลไทม์ จบด้วยการวิ่งเร็ว 60 วินาที
  • ไม่ต้องติดตั้งแป้นพิมพ์ภาษาเกาหลี: ทั้งปุ่มจริงและแป้นพิมพ์บนหน้าจอต่างป้อนเข้าสู่ตัวประกอบอักษรของบทเรียนเอง
  • ทำจนจบได้ทั้งหมดบนโทรศัพท์ — แตะปุ่มบนหน้าจอ — พร้อมขั้นตอนสุดท้ายที่แสดงวิธีเปิดการป้อนภาษาเกาหลีบน iOS, Android, Windows และ macOS

เอกสารอ้างอิงบทเรียนฉบับเต็ม

เนื้อหาทั้งหมดของบทเรียนนี้ — 29 ขั้นตอน ใน 6 ขั้น อ่านรวดเดียวเพื่อทบทวน หรือเรียนจากเวอร์ชันโต้ตอบด้านบน

ขั้นตอนที่ 1 · รู้จักแป้นพิมพ์ 키보드 소개

แป้นพิมพ์แบบสองชุด (두벌식, Dubeolsik) 두벌식 자판

คนเกาหลีเกือบทุกคนพิมพ์ด้วยผังแป้นเดียวกัน นั่นคือแป้นพิมพ์แบบสองชุดที่เรียกว่า 두벌식 (dubeolsik) ซึ่งเป็นมาตรฐานของชาติมาตั้งแต่ปี 1985 คำว่า “สองชุด” หมายถึงตัวอักษรถูกแบ่งออกเป็นสองกลุ่มพอดี — พยัญชนะและสระ — และแต่ละกลุ่มอยู่คนละฝั่งของแป้นพิมพ์ คุณไม่ต้องพิมพ์ทั้งบล็อกพยางค์ด้วยตัวเอง เพียงพิมพ์ตัวอักษรทีละตัวตามลำดับที่คุณออกเสียง แล้วคอมพิวเตอร์จะประกอบบล็อกให้คุณเอง

  • พยัญชนะอยู่ใต้มือซ้ายของคุณ — ㅂ ㅈ ㄷ ㄱ ㅅ อยู่แถวบน, ㅁ ㄴ ㅇ ㄹ ㅎ อยู่แถวหลัก, ㅋ ㅌ ㅊ ㅍ อยู่แถวล่าง
  • สระอยู่ใต้มือขวาของคุณ — ㅛ ㅕ ㅑ ㅐ ㅔ อยู่แถวบน, ㅗ ㅓ ㅏ ㅣ อยู่แถวหลัก, ㅠ ㅜ ㅡ อยู่แถวล่าง
  • Shift ให้ตัวอักษรคู่ — กด Shift ค้างไว้ แล้วพยัญชนะเสียงหนักทั้งห้า ㅃ ㅉ ㄸ ㄲ ㅆ จะปรากฏบน ㅂ ㅈ ㄷ ㄱ ㅅ พร้อมสระกว้างสองตัว ㅒ ㅖ บน ㅐ ㅔ
  • นั่นคือผังแป้นทั้งหมด: ปุ่มธรรมดา 26 ปุ่มและปุ่มที่ต้องกด Shift อีก 7 ปุ่ม เรียนรู้ 33 ปุ่ม แล้วคุณก็เขียนคำภาษาเกาหลีได้ทุกคำ

⌨️ มือซ้าย มือขวา

เพราะพยัญชนะอยู่ทางซ้ายเสมอและสระอยู่ทางขวาเสมอ การพิมพ์ภาษาเกาหลีจึงกลายเป็นจังหวะซ้าย-ขวา-ซ้าย-ขวาที่สม่ำเสมอ พยางค์เกาหลีก็สร้างขึ้นแบบเดียวกัน — พยัญชนะก่อน แล้วจึงสระ — มือของคุณจึงจำลองรูปทรงของภาษานี้ไปในตัว

พยางค์ประกอบกันอย่างไร 음절이 만들어지는 방법

การเขียนภาษาเกาหลีจะวางตัวอักษรซ้อนกันเป็นบล็อกสี่เหลี่ยม แต่คุณไม่ต้องวาดบล็อกเหล่านั้นเอง เพียงพิมพ์ตัวอักษรตามลำดับ แล้วมันจะประกอบกันเอง พิมพ์ ㅎ แล้ว ㅏ แล้ว ㄴ 한 ก็จะปรากฏทีละส่วน: ㅎ → 하 → 한 ไม่ต้องกดอะไรอีก ไม่มีเมนู ไม่มีปุ่มยืนยัน

  • พิมพ์ตัวอักษรตามลำดับการออกเสียง: พยัญชนะต้น แล้วสระ แล้วพยัญชนะสะกด (받침) หากพยางค์นั้นมี
  • บล็อกจะปิดตัวเองทันทีที่ตัวอักษรถัดไปใส่เข้าไปไม่ได้ พิมพ์ ㄱ ㅏ ㅁ ㅏ คุณจะได้ 가마 ไม่ใช่ 감아 — สระ ㅏ ตัวที่สองต้องมีพยัญชนะอยู่ข้างหน้า ดังนั้น ㅁ จึงกระโดดไปข้างหน้าเพื่อเริ่มบล็อกใหม่
  • การกระโดดนี้เรียกว่า “การขโมย 받침” และเป็นสิ่งที่คนพิมพ์ภาษาเกาหลีพึ่งพาพอดี พิมพ์ ㄱ ㅏ ㄱ ㅅ ㅏ คุณจะได้ 각사: 가 → 각 → 갃 → 각사 โดย ㅅ ถูกดึงออกจาก 받침 คู่ในทันทีที่ ㅏ มาถึง
  • Backspace ลอกออกทีละตัวอักษร ไม่ใช่ทีละบล็อก จาก 각 จะกลายเป็น 가 แล้วเป็น ㄱ แล้วจึงเป็นค่าว่าง

💡 ไม่ต้องติดตั้งอะไร

คุณไม่จำเป็นต้องมีแป้นพิมพ์ภาษาเกาหลีในคอมพิวเตอร์หรือโทรศัพท์เพื่อทำบทเรียนนี้ แป้นพิมพ์บนหน้านี้ทำงานทั้งหมดให้ — กดปุ่มบนแป้นพิมพ์ของคุณเอง หรือแตะปุ่มบนหน้าจอก็ได้ ขั้นที่ 28 จะแสดงวิธีเพิ่มแป้นพิมพ์ภาษาเกาหลีจริงลงในอุปกรณ์ของคุณเพื่อใช้ในที่อื่น ๆ

ขั้นตอนที่ 2 · ปุ่มพยัญชนะ 자음 키

ปุ่มบนแป้นพิมพ์

ปุ่มนิ้วและตำแหน่ง
ㅁ ㄴวางมือซ้ายบนแถวหลัก: A S D F ㅁ อยู่ที่ A ใต้นิ้วก้อย, ㄴ อยู่ที่ S ใต้นิ้วนาง สองตัวนี้คุณไม่ต้องขยับมือเลย
ㅇ ㄹวางมือในตำแหน่งเดิม ㅇ อยู่ที่ D ใต้นิ้วกลาง, ㄹ อยู่ที่ F ใต้นิ้วชี้ — ปุ่ม F มีปุ่มนูนเล็ก ๆ อยู่ คุณจึงหามันเจอได้เสมอโดยไม่ต้องมอง
ㅎ ㄱทั้งคู่เป็นปุ่มของนิ้วชี้ ㅎ อยู่ที่ G — อยู่ที่แถวหลักแล้วเอื้อมไปทางขวาของ F หนึ่งปุ่ม ㄱ อยู่ที่ R เหนือ F หนึ่งแถว ㄱ เป็นพยัญชนะที่ใช้บ่อยที่สุดในภาษาเกาหลี จึงคุ้มค่าที่จะทำให้คล่อง
ㅂ ㅈเลื่อนมือซ้ายขึ้นหนึ่งแถว ㅂ อยู่ที่ Q เหนือ A พอดี ใต้นิ้วก้อย ㅈ อยู่ที่ W เหนือ S พอดี ใต้นิ้วนาง ใช้นิ้วเดียวกับ ㅁ และ ㄴ — แค่สูงขึ้นหนึ่งแถว
ㄷ ㅅยังอยู่แถวบน ㄷ อยู่ที่ E เหนือ D ใต้นิ้วกลาง ㅅ อยู่ที่ T — นิ้วชี้เอื้อมขึ้นไปทางขวาบน เหนือ G ㅅ เป็น 받침 ที่พบบ่อยมาก จึงจะโผล่มาอยู่เรื่อย ๆ
ㅋ ㅌลดมือซ้ายลงหนึ่งแถวใต้แถวหลัก ㅋ อยู่ที่ Z ใต้นิ้วก้อย และ ㅌ อยู่ที่ X ใต้นิ้วนาง ทั้งคู่เป็นเสียงพ่นลมคู่ของ ㄱ และ ㄷ และอยู่ในมุมที่ใช้น้อยที่สุดเพราะภาษาเกาหลีใช้มันน้อยกว่า
ㅊ ㅍแถวล่างเดิม ㅊ อยู่ที่ C ใต้นิ้วกลาง และ ㅍ อยู่ที่ V ใต้นิ้วชี้ นั่นครบพยัญชนะพื้นฐานทั้ง 14 ตัว: สามแถว ใช้มือซ้ายอย่างเดียว

ขั้นตอนที่ 3 · ปุ่มสระ 모음 키

ปุ่มบนแป้นพิมพ์

ปุ่มนิ้วและตำแหน่ง
ㅗ ㅓตอนนี้ถึงมือขวา วางไว้บน J K L แล้วเอื้อม ㅗ อยู่ที่ H ให้นิ้วชี้เอื้อมไปทางซ้าย ㅓ อยู่ที่ J ปุ่มหลักที่อยู่ใต้นิ้วชี้พอดี — ปุ่ม J ก็มีปุ่มนูนเช่นกัน
ㅏ ㅣสองตัวนี้ไม่ต้องขยับเลย ㅏ อยู่ที่ K ใต้นิ้วกลาง และ ㅣ อยู่ที่ L ใต้นิ้วนาง ㅏ เป็นสระที่ใช้บ่อยที่สุดในภาษาเกาหลี และมันก็อยู่ใต้นิ้วที่พักอยู่แล้วพอดี
ㅛ ㅕเลื่อนมือขวาขึ้นหนึ่งแถว ทั้งคู่เป็นปุ่มของนิ้วชี้: ㅛ อยู่ที่ Y เอื้อมขึ้นไปทางซ้ายบน และ ㅕ อยู่ที่ U เหนือ J พอดี สังเกตรูปแบบ — สระเสียง y อย่าง ㅛ ㅕ อยู่เหนือคู่พื้นฐาน ㅗ ㅓ ของมันหนึ่งแถว
ㅑ ㅐยังอยู่แถวบน ㅑ อยู่ที่ I เหนือ K พอดี ใต้นิ้วกลาง — อยู่เหนือคู่พื้นฐาน ㅏ ของมันหนึ่งแถวอีกเช่นกัน ㅐ อยู่ที่ O ใต้นิ้วนาง
ㅔㅔ อยู่ที่ P ปุ่มแถวบนใต้นิ้วก้อยขวา — เป็นสระที่อยู่ไกลจากแถวหลักที่สุด ในภาษาเกาหลีปัจจุบัน ㅐ และ ㅔ ออกเสียงเกือบเหมือนกัน และอยู่ติดกันบน O และ P จึงควรจำเป็นคู่
ㅠ ㅜ ㅡสามปุ่มเรียงกันตามแถวล่าง: ㅠ ที่ B, ㅜ ที่ N, ㅡ ที่ M B ต้องให้นิ้วชี้ซ้ายเอื้อมไป ส่วน N และ M อยู่ใต้นิ้วชี้ขวา ㅡ ที่ M สำคัญกว่าที่เห็น — เป็นสระที่อยู่ใน 은, 는, 를 และท้ายไวยากรณ์อื่น ๆ ส่วนใหญ่

ㅃ ㅉพยัญชนะเสียงหนักทั้งห้าคือปุ่มธรรมดาที่กด Shift ค้างไว้ ㅃ คือ Shift + Q (ที่ ㅂ อยู่) และ ㅉ คือ Shift + W (ที่ ㅈ อยู่) เพราะทั้งคู่เป็นปุ่มมือซ้าย ให้กด Shift ฝั่งขวาค้างด้วยนิ้วก้อยขวาขณะที่มือซ้ายพิมพ์ — แป้นพิมพ์จะเน้นว่าควรใช้ Shift ตัวไหน บนหน้าจอสัมผัส ให้แตะ ⇧ ก่อน — มันจะค้างไว้พอดีหนึ่งปุ่ม
ㄸ ㄲ ㅆกฎเดิม เพิ่มอีกสามปุ่ม: ㄸ คือ Shift + E, ㄲ คือ Shift + R, ㅆ คือ Shift + T — ล้วนเป็นปุ่มมือซ้าย จึงกด Shift ฝั่งขวาค้างด้วยนิ้วก้อยขวาอีกครั้ง สามตัวนี้โผล่มาตลอด — 진짜, 꼭, 있어요 — จึงคุ้มที่จะฝึกรีเฟล็กซ์ Shift ตั้งแต่ตอนนี้
ㅒ ㅖShift ใช้ได้กับฝั่งสระเช่นกัน แต่มีแค่สองปุ่ม: ㅒ คือ Shift + O (เหนือ ㅐ) และ ㅖ คือ Shift + P (เหนือ ㅔ) ปุ่มเหล่านี้เป็นปุ่มมือขวา คราวนี้จึงใช้ Shift ฝั่งซ้ายด้วยนิ้วก้อยซ้าย — ใช้มือฝั่งตรงข้ามกับตัวอักษรเสมอ สระอื่น ๆ ที่คุณจะต้องใช้ ล้วนเป็นปุ่มธรรมดาหนึ่งปุ่ม หรือปุ่มธรรมดาสองปุ่มพิมพ์ต่อกัน

ขั้นตอนที่ 5 · พิมพ์พยางค์ 음절 입력

ฝึกพิมพ์

มุ่งความแม่นยำ ไม่ใช่ความเร็ว ช้าแต่ถูกสร้างนิสัยที่ดี เร็วแต่ผิดสร้างนิสัยที่คุณต้องมาแก้ทีหลัง ความเร็วจะมาเอง เมื่อนิ้วของคุณเลิกไล่หาปุ่ม

ทั้งหมดนี้อยู่ใต้มือขวาของคุณ ถ้าเผลอก้มมองแป้น ลองเรียกชื่อนิ้วก่อนกด — นิ้วชี้ นิ้วกลาง นิ้วนาง นิ้วก้อย

แต่ละพยางค์กดสองครั้ง และทุกครั้งเป็นมือซ้ายแล้วมือขวา ไม่มีปุ่มไหนที่ต้องกดเพื่อ “ปิด” บล็อก — พอสระลงตำแหน่ง พยางค์ก็เสร็จ และแบบฝึกก็ไปตัวถัดไป

แต่ละพยางค์กดสามครั้ง: ซ้าย ขวา ซ้าย ดูบล็อกเปลี่ยนรูปเมื่อตัวอักษรที่สามลงตำแหน่ง — 하 กลายเป็น 한 ทันทีที่คุณกด ㄴ

ㅘ ไม่มีปุ่มของตัวเอง — คุณพิมพ์ ㅗ แล้ว ㅏ สองตัวก็รวมกัน หลักการเดียวกันกับ ㅝ (ㅜ + ㅓ), ㅢ (ㅡ + ㅣ), ㅙ (ㅗ + ㅐ) และ ㅟ (ㅜ + ㅣ) มีแค่ ㅐ ㅔ ㅒ ㅖ ที่มีปุ่มของตัวเอง

พิมพ์ภาษาเกาหลีบนอุปกรณ์ของคุณเอง 내 기기에 한국어 자판 추가하기

อย่างแรก พูดกันตรง ๆ: การฝึกที่นี่ไม่ต้องติดตั้งอะไรเลย แบบฝึกทุกอันในบทเรียนนี้ใช้งานได้แม้อุปกรณ์ของคุณไม่มีแป้นพิมพ์ภาษาเกาหลีเลย — หน้านี้อ่านว่าคุณกดปุ่มจริงปุ่มไหน และบนมือถือคุณก็แค่แตะปุ่มบนหน้าจอ แต่เมื่อคุณอยากส่งข้อความหาเพื่อนชาวเกาหลี ค้นหาเป็นภาษาเกาหลี หรือกรอกแบบฟอร์ม คุณจะต้องมีแป้นพิมพ์ภาษาเกาหลีจริงบนอุปกรณ์ นี่คือวิธีเพิ่ม ทุกที่ด้านล่างนี้ ให้เลือกผังแบบสองชุด / 두벌식 ธรรมดา — เป็นผังเดียวกับที่คุณเพิ่งเรียนมา

  • iPhone / iPad — Settings → General → Keyboard → Keyboards → Add New Keyboard… → Korean จากนั้นมันจะถามว่าต้องการผังแบบไหน: เลือก Standard (นั่นคือ 두벌식 ส่วน “10 Key” เป็นผังแป้นโทรศัพท์ขนาดเล็ก) สลับแป้นพิมพ์โดยกดปุ่มลูกโลก 🌐 ที่ด้านล่างของแป้นพิมพ์ค้างไว้
  • Android — ทำจากแป้นพิมพ์เองง่ายที่สุด: เปิดแอปใดก็ได้ที่พิมพ์ได้ แตะไอคอนตั้งค่า ⚙ บนแถบด้านบนของแป้นพิมพ์ → Languages → Add keyboard → Korean → 2벌식 (สองชุด) → Done ถ้าผ่านแอปการตั้งค่าจะเป็น Settings → System → Keyboard → On-screen keyboard → Gboard → Languages → Add keyboard การสลับขณะพิมพ์ ให้แตะแป้นเว้นวรรคค้างไว้
  • Windows 11 — Settings → Time & language → Language & region → Add a language → ค้นหา 한국어 (Korean) → Next → Install สลับการป้อนด้วย Win + Space เมื่อเลือกภาษาเกาหลีแล้ว ปุ่ม Alt ขวาจะสลับระหว่างฮันกึลกับภาษาอังกฤษ — บนแป้นพิมพ์เกาหลี ปุ่มนั้นจะพิมพ์ว่า 한/영
  • macOS — System Settings → Keyboard → Text Input → Edit… → คลิก + → Korean → 2-Set Korean → Add สลับแหล่งป้อนข้อมูลด้วย Ctrl + Space เมื่อเปิดใช้ภาษาเกาหลี ปุ่ม Caps Lock จะสลับระหว่างฮันกึลกับภาษาอังกฤษ

🌏 การฝึกของคุณใช้ได้ต่อ

ทั้งหมดนี้คือผัง 두벌식 เดียวกับที่คุณฝึกมา: พยัญชนะซ้าย สระขวา Shift สำหรับตัวอักษรคู่ ไม่มีอะไรต้องเรียนใหม่ — ความจำของกล้ามเนื้อที่คุณสร้างบนหน้านี้ใช้ได้ทันทีที่คุณสลับโทรศัพท์หรือแล็ปท็อป

คุณพิมพ์ภาษาเกาหลีได้แล้ว! — 이제 한국어를 칠 수 있어요!

ทำได้ยอดเยี่ยม — คุณได้เรียนครบทั้ง 33 ปุ่มของแป้นพิมพ์ 두벌식 พิมพ์พยางค์ทั้งที่มีและไม่มี 받침 จัดการสระประสมได้ และวิ่งสปรินต์ครบ 60 วินาที รักษาความเร็วไว้กับแป้นพิมพ์อิสระที่อยู่ใต้บทเรียนนี้: พิมพ์คำภาษาเกาหลีคำไหนก็ได้ที่คุณชอบ แล้วดูบล็อกประกอบตัวเอง 화이팅!
