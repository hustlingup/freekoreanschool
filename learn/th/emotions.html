อารมณ์: 감정

อ่านคำอธิบายและตัวอย่าง แล้วฝึกตามจังหวะของคุณ เนื้อหาทั้งหมดอยู่ในหน้านี้

อารมณ์พื้นฐาน 기본 감정

อารมณ์ภาษาเกาหลี (감정)

คำอารมณ์ภาษาเกาหลีส่วนใหญ่เป็นคำคุณศัพท์ในรูปพจนานุกรม ต่างจากภาษาอังกฤษ ("I am happy") คำคุณศัพท์ภาษาเกาหลีทำหน้าที่เหมือนกริยาและผันได้โดยตรง: 행복해요 (มีความสุข) โดยไม่ต้องมีคำว่า "am" แยกต่างหาก รูปพจนานุกรมลงท้ายด้วย -다 เช่น 행복하다, 슬프다, 무섭다 ตัดคำว่า -다 ออกแล้วเติม -아요/-어요 สำหรับรูปปัจจุบันแบบสุภาพ คำศัพท์อารมณ์มีประโยชน์อย่างยิ่งในการพูดถึงซีรีส์เกาหลี ชีวิตประจำวัน และความรู้สึกส่วนตัว

คำคุณศัพท์ผันเหมือนกริยา

행복하다 → 행복해요 (ฉันมีความสุข) 슬프다 → 슬퍼요 (ฉันเศร้า) 피곤하다 → 피곤해요 (ฉันเหนื่อย) การลงท้ายด้วย -아요/-어요 ทำให้คำคุณศัพท์กลายเป็นรูปสุภาพและรูปปัจจุบันพร้อมกัน

คำตอบ

행복하다

การผันคำคุณศัพท์อารมณ์ 감정 형용사 활용

เพื่อใช้คำคุณศัพท์อารมณ์ในการสนทนาสุภาพ ให้ตัด -다 ออกจากรูปพจนานุกรมแล้วเติมวิภัตติปัจจุบันแบบสุภาพ สำหรับรากศัพท์ที่ลงท้ายด้วย 하: 하다 → 해요 (เช่น 행복하다 → 행복해요) สำหรับรากศัพท์ที่มีสระเสียงสว่าง (ㅏ, ㅗ) ให้เติม -아요 ส่วนรากศัพท์อื่นๆ ให้เติม -어요 ซึ่งมักมีการเปลี่ยนรูปสระร่วมด้วย เช่น 슬프다 จะตัด ㅡ ออก: 슬프 + 어요 → 슬퍼요 รากศัพท์ที่ลงท้ายด้วย ㅂ เป็นคำผันแบบไม่ปกติ โดย ㅂ จะเปลี่ยนเป็น 우 เช่น 무섭다 → 무서우 + 어요 → 무서워요 (เช่นเดียวกับ 외롭다 → 외로워요 และ 부끄럽다 → 부끄러워요) รูปแบบเดียวกันนี้ใช้ได้กับคำกริยาแสดงสภาพ (คำคุณศัพท์) ส่วนใหญ่ในภาษาเกาหลี

ตารางผันเร็ว

행복하다 → 행복해요 슬프다 → 슬퍼요 화나다 → 화나요 무섭다 → 무서워요 피곤하다 → 피곤해요 기쁘다 → 기뻐요 โปรดสังเกตว่า 슬프다 → 슬퍼요 (ㅡ หายไปก่อน -어요)

신나다 ในวัฒนธรรมป๊อป

신나다 และ 신나요 พบได้ทั่วไปในวัฒนธรรมป๊อปเกาหลี เพลง K-Pop มักใช้ 신나 เพื่อบรรยายจังหวะหรืออารมณ์ที่น่าตื่นเต้น นอกจากนี้ยังได้ยินคำอุทาน 신난다! (สนุกจังเลย!) ในงานอีเวนต์และงานปาร์ตี้ต่างๆ

기분 vs 감정

기분 = อารมณ์ สภาวะความรู้สึกทั่วไป (เปลี่ยนได้ตามบริบท) 감정 = อารมณ์ความรู้สึกเฉพาะเจาะจง (เช่น ความโกรธ ความสุข ความกลัว) 기분이 좋아요 = ตอนนี้ฉันรู้สึกดี 감정을 표현하다 = แสดงออกทางอารมณ์

อารมณ์ที่ซับซ้อน 복잡한 감정

อารมณ์ที่ลึกซึ้ง (깊은 감정)

ภาษาเกาหลีมีคำแสดงอารมณ์หลายคำที่ไม่มีคำแปลตรงตัวเป็นภาษาอังกฤษเพียงคำเดียว 그립다 (กือริพดา) หมายถึงความคิดถึงคนหรือสิ่งใดสิ่งหนึ่ง คือความอาลัยถึงบุคคลหรือสถานที่อันเป็นที่รักที่ไม่อยู่ตรงหน้า 외롭다 (เออโรพดา) คือความเหงา แต่มีมิติทางวัฒนธรรมของความโดดเดี่ยวที่ลึกซึ้งกว่านั้น 부끄럽다 (ปุกือรอบดา) คือความอับอายหรือความขี้อาย 뿌듯하다 (ปุดือทาดา) คือความภาคภูมิใจหรือความอิ่มเอมใจอันอบอุ่นจากความสำเร็จ คือความรู้สึกที่คุณได้รับเมื่อทำสิ่งที่ยากสำเร็จ หรือเมื่อเห็นคนที่คุณรักประสบความสำเร็จ

한 (ฮัน) — ความเศร้าที่แปลไม่ได้

한 (ฮัน) เป็นอารมณ์ที่เฉพาะเจาะจงทางวัฒนธรรม คือความเศร้าลึกๆ ที่ผสมผสานกับความอดทนเข้มแข็ง มีรากฐานมาจากความทุกข์ทรมานในประวัติศาสตร์แต่ถูกเปลี่ยนเป็นพลังสร้างสรรค์ ได้ยินในพันโซรี (อุปรากรพื้นบ้านเกาหลี) ถูกบรรยายไว้ในบทกวี และถูกกล่าวถึงในการพูดคุยเรื่องอัตลักษณ์เกาหลี ไม่ใช่คำที่ควรใช้แบบลำลอง แต่สำคัญอย่างยิ่งต่อความเข้าใจทางวัฒนธรรม

รูปประโยคแสดงอารมณ์ 감정 문장

รูปประโยคแสดงอารมณ์ที่ใช้บ่อย 감정 표현 문장

รูปประโยคหลายแบบมีประโยชน์เป็นพิเศษสำหรับการแสดงอารมณ์ในภาษาเกาหลี "보고 싶어요" (คิดถึงคุณ / อยากเจอคุณ) ใช้ 보다 (ดู) รวมกับ -고 싶다 (อยากจะ) ส่วน "감동받았어요" (ฉันซาบซึ้งใจ) ใช้ 감동 (ความรู้สึกซาบซึ้งลึกซึ้ง) รวมกับ 받다 (ได้รับ) และ "괜찮아요" (ฉันโอเค / ไม่เป็นไร) เป็นหนึ่งในวลีที่ใช้ได้หลากหลายที่สุด ใช้พูดได้ทั้ง "ฉันสบายดี" "ไม่เป็นไร" "ไม่มีปัญหา" และ "ช่างมันเถอะ"

괜찮아요 — สำนวนอเนกประสงค์

괜찮아요 แปลตรงๆ ว่า "ไม่เป็นไร/โอเค" ใช้ปลอบใจคนอื่นว่าคุณไม่เป็นไร (เช่น หลังจากสะดุดล้ม) ใช้ตอบรับข้อเสนอที่คุณเคยปฏิเสธไปก่อนหน้านี้ ใช้พูดว่า "ไม่เป็นไร ขอบคุณ" (ปฏิเสธอย่างสุภาพ) หรือใช้แสดงว่า "รับได้ ยอมรับได้" การเข้าใจน้ำเสียงให้ถูกต้องเป็นสิ่งสำคัญ — คำเดียวกัน แต่ความหมายต่างกันมาก
